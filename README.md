# Illegal Basketball (ready to host)

Upload every file in this folder to the top level of a GitHub repo, then on Render:
New → Web Service → this repo → Language **Node**, Build Command `npm install`,
Start Command `node server.js`, Instance Type **Free**, Health Check Path `/health`.
The game is served at your Render address and online play uses the same address.
Fonts: Barlow and Big Shoulders Display, SIL Open Font License (OFL-*.txt).
